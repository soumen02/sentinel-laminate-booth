# Sentinel · Laminate booth page

Scroll-driven story page for the Sentinel / Laminate event screen.

- Live site: GitHub Pages (see repo Settings → Pages)
- Kiosk mode: open the site with `?tour` (or `#tour`) at the end of the URL to start the auto tour.
- Everything is static: `index.html` plus the WebP layers in `assets/`.

Scan imagery is derived from the public longitudinal MS MRI database (Lesjak et al., Laboratory of Imaging Technologies, University of Ljubljana), licensed CC BY. De-identified research data. For research and educational use; not for clinical diagnosis or patient care.
